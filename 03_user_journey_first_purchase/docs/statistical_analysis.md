# Statistical Analysis & Confidence

The project includes uncertainty and significance testing so descriptive differences are not automatically treated as decision-grade evidence.

- Median journey duration: **11.02 days** (95% bootstrap CI: 10.75–11.27)
- 7-day purchase rate: **20.6%** (95% bootstrap CI: 19.2%–22.1%)
- Average sessions before purchase: **3.96** (95% bootstrap CI: 3.89–4.03)

Kruskal-Wallis tests compare journey duration across acquisition media and devices because normality is not assumed. Statistical significance is treated as evidence for investigation—not proof of causality.
