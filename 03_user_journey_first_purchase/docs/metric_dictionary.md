# Metric Dictionary
| Metric | Definition | Decision Use |
|---|---|---|
| Sessions Before Purchase | Sessions from first touch through first purchase | Friction / consideration |
| Events Before Purchase | Product/site events before first purchase | Journey complexity |
| Journey Duration | Days from first touch to first purchase | Time-to-value |
| Fast Purchase 7d | Purchase completed within 7 days | Journey quality KPI |
| First Purchase Revenue | Revenue on first purchase | Initial customer value |
| Revenue / Session | First purchase revenue divided by sessions | Journey efficiency |
| Acquisition Medium | First recorded acquisition source | Channel-quality segmentation |

A faster journey is not automatically better if revenue or customer quality deteriorates. Use speed together with revenue and retention where available.
