# Experiment Plan — Accelerate First Purchase

## Hypothesis
A continuity-focused landing/onboarding experience for high-friction acquisition traffic will reduce sessions required before first purchase and increase 7-day first-purchase conversion.

## Control
Current acquisition landing and standard journey.

## Treatment
Message-matched landing experience with:
- clearer value proposition
- persistent cart/recently viewed continuity
- stronger next-best-action guidance
- trust/shipping information earlier in the journey

## Primary Metric
7-day first-purchase conversion.

## Secondary Metrics
Sessions before purchase, median time to purchase, first-purchase revenue, revenue/session.

## Guardrails
Refund/cancellation rate, AOV, support contacts, page performance.

## Decision
Ship only if journey speed improves without reducing purchase quality.
