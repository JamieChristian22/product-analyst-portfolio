# Budget Reallocation Scenario

The budget-reallocation output is a **directional scenario**, not an optimized financial forecast.

It preserves the total simulated marketing budget while shifting weight toward channels with stronger modeled retention and scenario LTV:CAC, and away from channels classified Reduce/Pause.

Before a real reallocation:
1. Validate attribution.
2. Confirm gross-margin and recurring-revenue assumptions.
3. Run incrementality tests.
4. Set channel-specific spend caps.
5. Monitor marginal CAC rather than historical average CAC.
