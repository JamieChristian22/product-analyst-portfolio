# Stakeholder Map & RACI

| Work | Product | Analytics | Design | Engineering | Finance/Growth | Leadership |
|---|---|---|---|---|---|---|
| Problem definition | A | R | C | C | C | I |
| Metric definition | C | A/R | C | C | C | I |
| Experience hypothesis | A | C | R | C | I | I |
| Instrumentation | C | A/R | C | R | I | I |
| Experiment design | A | R | C | C | C | I |
| Implementation | A | C | R/C | R | I | I |
| Analysis/readout | C | A/R | I | I | C | I |
| Investment decision | R | C | I | C | C | A |

R = Responsible • A = Accountable • C = Consulted • I = Informed

## Stakeholder Principle
Product Analytics should make disagreements measurable. Clarify the decision, surface assumptions, define evidence thresholds, and document the final tradeoff.
