# Product Analytics Agile Playbook

## Discovery
Clarify problem, decision, baseline, users, and business context.

## Backlog Refinement
Ensure analytics requirements, instrumentation, success metrics, and guardrails are represented before development.

## Definition of Ready
- User problem defined
- KPI baseline available
- Hypothesis documented
- Instrumentation specified
- Acceptance criteria testable
- Dependencies identified

## Sprint
Partner with Product/Engineering on event implementation and QA.

## Definition of Done
- Functional acceptance criteria pass
- Analytics events validated
- Experiment assignment validated if applicable
- Dashboard/query/readout path available
- Known data limitations documented

## Post Launch
Monitor adoption, primary outcome, guardrails, reliability, and unexpected segment behavior.
