# Product Analytics QA Standard

- [x] Metric denominator is explicit
- [x] Event/user grain is documented
- [x] Observed facts separated from modeled assumptions
- [x] Correlation not presented as causation
- [x] Primary metrics have guardrails
- [x] Opportunity sizing is labeled as scenario/proxy
- [x] Experiments require instrumentation QA
- [x] Decisions are documented
- [x] Synthetic/simulated data is disclosed where used
- [x] No fabricated dashboard screenshots are required to prove analytical skill
