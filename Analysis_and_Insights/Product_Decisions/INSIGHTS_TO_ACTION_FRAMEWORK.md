# Insights-to-Action Framework

**Observation → Evidence → Why It Matters → Root-Cause Hypothesis → Product Recommendation → Priority → Experiment → Success Metric → Guardrail → Business Impact → Decision**

## Rules
- Separate observed facts from hypotheses.
- Do not make causal claims from segmentation alone.
- Quantify opportunity when assumptions are transparent.
- Pair every primary metric with guardrails.
- Define the decision before running analysis.
- Record what was adopted, rejected, or still requires validation.
