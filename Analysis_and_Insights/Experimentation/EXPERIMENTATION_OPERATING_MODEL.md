# Experimentation Operating Model

1. Define the decision.
2. State the causal hypothesis.
3. Choose the unit of randomization.
4. Define primary, secondary, and guardrail metrics.
5. Establish baseline and sample-size requirements.
6. Validate instrumentation before launch.
7. Run the experiment without peeking-driven decisions.
8. Analyze effect size, uncertainty, and segment heterogeneity.
9. Make a ship / iterate / stop decision.
10. Monitor post-launch durability.

Observational analysis generates hypotheses; controlled experiments validate causal product impact.
