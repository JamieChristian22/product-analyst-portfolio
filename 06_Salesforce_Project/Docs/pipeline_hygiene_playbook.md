# Pipeline Hygiene Playbook
1. Review stale opportunities weekly.
2. Require next step and next activity on material deals.
3. Correct overdue close dates.
4. Move dead deals to Closed Lost with a governed loss reason.
5. Audit probability against stage definitions.
6. Escalate high-value, high-risk deals.
7. Track aging by stage and owner.
8. Monitor forecast movement and push rates.
