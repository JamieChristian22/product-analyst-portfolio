# KPI Dictionary
| KPI | Definition | Decision |
|---|---|---|
| Open Pipeline | Amount for non-closed opportunities | Capacity |
| Weighted Pipeline | Amount × probability | Probability-adjusted outlook |
| Win Rate | Closed Won / all closed deals | Sales effectiveness |
| Avg Deal Size | Average opportunity amount | Deal economics |
| Pipeline Coverage | Open pipeline / quota | Coverage sufficiency |
| Stale Deal | Open deal with ≥21 days inactivity | Pipeline hygiene |
| Overdue Deal | Open deal past close date | Forecast risk |
| Sales Velocity | Opportunities × win rate × deal size / sales cycle | Revenue throughput |
