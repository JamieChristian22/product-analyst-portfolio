# Product Funnel Analysis

The Salesforce opportunity lifecycle is modeled as a product funnel:

1. Prospecting
2. Qualification
3. Discovery
4. Proposal
5. Negotiation
6. Closed Won / Closed Lost

Product analysis focuses on where users and opportunities become stuck, where aging increases, and where workflow interventions can reduce friction.

## Diagnostic Questions
- Which stages accumulate the most pipeline?
- Which stages have the highest average age?
- Where are stale opportunities concentrated?
- Which owners or segments experience greater workflow friction?
- Which stage transitions should receive automation, nudges, or UX improvements?

This turns pipeline reporting into product-behavior diagnosis.
