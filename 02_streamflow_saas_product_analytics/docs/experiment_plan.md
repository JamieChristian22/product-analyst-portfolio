# Experiment Plan — Activation Onboarding

## Hypothesis
Guiding new users to create a project and upload content during onboarding will increase activation and improve subsequent retention.

## Control
Current onboarding.

## Treatment
Checklist-driven onboarding emphasizing:
1. Create first project
2. Upload first video
3. Export first clip

## Primary Metric
Activation rate within 7 days.

## Secondary Metrics
7-day active rate, feature breadth, export adoption, paid-plan conversion.

## Guardrails
Support contacts, error rate, onboarding abandonment, time-to-first-value.

## Decision Rule
Ship only when the activation lift is both statistically and practically meaningful and guardrails remain healthy.
