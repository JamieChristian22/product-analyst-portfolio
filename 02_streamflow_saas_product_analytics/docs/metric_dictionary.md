# SaaS Metric Dictionary

| Metric | Definition | Product Use |
|---|---|---|
| DAU | Distinct active users per day | Daily engagement |
| MAU | Distinct active users per month | Product reach |
| DAU/MAU | Average daily engagement relative to monthly reach | Stickiness proxy |
| Activation | User completes create_project + upload_video | Early value realization hypothesis |
| Feature Adoption | Users using feature / total users | Feature reach |
| Power User | ≥8 events and ≥3 distinct features | Deep engagement proxy |
| Next-Month Retention | User active in month after first active month | Retention proxy |
| Cancellation Signal | Users with cancel_subscription / users | Churn-risk indicator |
| Revenue/User | Observed revenue / distinct users | Monetization efficiency |
| Paid Users 30d | Non-Free users active in final 30 days | Recent paid footprint |

These definitions are portfolio assumptions and should be aligned with real product instrumentation before production use.
