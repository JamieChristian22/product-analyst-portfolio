# Data Dictionary

| Field | Meaning |
|---|---|
| event_date | Product event timestamp/date |
| user_id | Simulated user identifier |
| event_name | Product behavior/event |
| plan_type | Free, Basic, Pro, Enterprise |
| acquisition_channel | User acquisition source |
| revenue_usd | Observed event-level revenue field |

Raw grain: one row per product event.
