# Metric Dictionary
| Metric | Definition | Decision Use |
|---|---|---|
| Step Conversion | Users reaching next stage / prior stage | Funnel health |
| Drop-off | Prior-stage users - next-stage users | Friction volume |
| Overall Conversion | Purchasers / viewers | North-star funnel outcome |
| Revenue | Purchase-event revenue | Business impact |
| AOV | Revenue / purchases | Purchase quality |
| Time to Purchase | First purchase timestamp - first view | Journey speed |
| Friction Index | Non-conversion × relative time-to-purchase | Segment prioritization |
